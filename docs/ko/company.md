# 사내 배포 안내

처음 쓰는 사람 · 관리 정책 한 장 · 어디로 나가나 · 다 됐는지 재기 · 막는 것의 한계

---

한 쪽짜리입니다. deel 을 처음 쓰는 사람과, 여러 사람에게 깔아 주는 담당자를 위한 것입니다.
자세한 것은 표마다 걸어 둔 문서에 있습니다.

## 처음 쓰는 사람

```bash
npm i -g deel-local-cli     # 늘 npm 의 최신 판을 받습니다
deel setup                  # 사내 게이트웨이 주소와 열쇠를 넣습니다
deel doctor                 # 붙기 전 조건을 한 줄씩 봅니다
deel                        # 작업할 폴더에서 켭니다
```

막히면 `deel doctor` 화면을 **그대로** 담당자에게 보내세요. 어느 줄이 막혔는지와 왜인지가
적혀 있고, 열쇠 같은 비밀은 한 글자도 안 찍힙니다.

스위치는 셋뿐입니다. 나머지는 몰라도 됩니다.

| 스위치 | 무엇을 정하나 | 바꾸는 법 |
|---|---|---|
| **승인** | 바꾸기 전에 얼마나 묻나 — `auto`(맡김: 안 묻고, 되돌리기가 안전망) · `confirm`(되돌릴 수 없는 명령만) · `strict`(파일·명령 전부, **바뀔 내용을 먼저 보여 줌**) | Shift+Tab · `/mode` |
| **작업 모드** | 무슨 일을 하나 — 기본 `종합` 이 요청을 보고 알아서 고릅니다 | `/work` |
| **나가는 범위** | `이 안`(기본) · `바깥` · `봉인`(회사 밖으로 아무것도 안 나감) | `--offline` · 관리 정책 |

`auto` 는 **맡기는** 모드입니다. 도구 승인을 안 묻는 것에 더해, 모델이 되묻거나(「어느 쪽으로 할까요?」)
「설계하고 만들어줘」 에 계획부터 내놓아도 **60초 안에 답이 없으면 알아서 진행합니다** — 되묻기는 스스로
판단하게 하고, 계획은 그대로 이어서 만듭니다. 자리에 있으면 그 사이에 답하면 됩니다. 기다리는 시간은
설정의 `askWait`(초, `0` 이면 아예 안 물음)입니다. 묻는 모드(`confirm` · `strict`)는 시한 없이 기다립니다 —
답을 기다리라고 고른 모드이기 때문입니다.

잘못 고쳤으면 `/undo` 로 한 턴씩 되돌립니다. 이번 대화에서 무엇이 바뀌었는지는 `/diff`,
지금 어디에 붙어 있고 무엇이 걸려 있는지는 `/status` 입니다.

## 담당자 — 정책 파일 한 장

사용자가 못 고치는 자리에 둡니다. 윈도우는 `%ProgramData%\deel\policy.json`, 맥·리눅스는
`/etc/deel/policy.json` 입니다.

```json
{
  "baseUrl": "https://ai-gw.example.corp/v1",
  "offline": true,
  "approval": "strict",
  "permissions": { "deny": ["WebFetch", "Bash(curl*)", "Bash(git push*)"] }
}
```

| 칸 | 이 한 줄로 되는 것 |
|---|---|
| `baseUrl` | 이 게이트웨이에만 붙습니다 |
| `offline` | 회사 밖(공인 주소)으로는 아무것도 안 나갑니다. 사내망은 됩니다 |
| `approval` | 파일을 바꾸거나 명령을 돌리기 전에 **늘 사람이 diff 를 보고** 정합니다. `/mode` · Shift+Tab · `--yes` · 「앞으로 묻지 않기」 로 못 풉니다 |
| `permissions.deny` | 적은 도구·명령은 사람이 허락해도 안 돕니다 |

정책은 설정을 이기고, 넓히지는 못합니다 — 켤 수는 있어도 끌 수 없고, 금지를 더할 수는
있어도 사용자의 금지를 지우지 못합니다. 걸렸는지는 `deel doctor` 의 「승인 바닥」 줄과
`/mode` 로 봅니다. 자세한 것은 [관리 정책](config.md#관리-정책-it-가-정하는-것).

## 어디로 나가나

선을 넘는 길은 넷뿐입니다 — **모델 게이트웨이 · 웹 읽기(WebFetch) · 플러그인 받기 · MCP 서버.**
소스와 파일 내용이 가는 곳은 그중 모델 게이트웨이 **하나**입니다. 봉인(`offline`)은 뒤의 셋을
잠급니다 — MCP 서버는 아예 안 띄웁니다.

| | |
|---|---|
| **게이트웨이 뒤** | deel 이 보내는 곳은 프로필의 주소 하나입니다. 그 주소가 사내 게이트웨이면, 게이트웨이가 사내 모델로 보내는지 바깥 API 로 넘기는지는 **게이트웨이 설정**입니다. deel 이 가릴 수 있는 자리가 아니니 게이트웨이 담당자에게 확인하세요 |
| **사내망** | 10.x · 172.16~31.x · 192.168.x 는 봉인에서도 「이 안」 입니다. 지키는 경계는 「회사 밖으로 안 나간다」 이지 랜선을 뽑는 것이 아닙니다 |
| **남는 기록** | 무엇을 어디로 보냈는지는 `.deel/audit.jsonl` 과 `deel stats` 에 남습니다 |

## 완료 검사

모델이 「다 됐습니다」 라고 해도 그 말을 믿지 않게 할 수 있습니다. 저장소의 `.deel/config.json` 이나
이 PC 설정에 검사 명령 하나를 적습니다.

```json
{ "check": "npm test", "checkRounds": 3 }
```

모델이 무엇을 바꾸고 끝내려 하면 deel 이 **직접** 그 명령을 돌립니다. 실패하면 출력을 모델에게
돌려주고 이어서 고치게 합니다(기본 3판). 끝내 실패하면 실패로 끝냅니다 — `deel run` 은 종료코드 **8**
이라 CI 가 그대로 빨개집니다. 이번만 다른 검사를 쓰려면 `deel run --check "npm run lint"`.

검사 명령도 모델이 부른 명령과 **같은 관문**을 지납니다 — 정책 금지 규칙, 훅, 승인(`strict` 면 묻습니다),
위험 명령 차단. 설정에 적혀 있다고 건너뛰지 않습니다. 아무것도 안 바꾼 턴에는 돌지 않습니다.

## 골든셋

「이 모델과 deel 이 우리 일을 몇 개나 해내나」 는 검사 1만여 개로는 못 잽니다. 그건 도구가 약속대로
도는지를 재는 것이고, **실제 일을 해내는지**는 사내 과제로 재야 합니다.

```bash
deel eval --init        # golden/ 에 예제 과제 다섯을 만듭니다 — 여기에 사내 과제를 더합니다
deel eval               # 과제마다 임시 폴더에서 돌리고 채점합니다
deel eval --repeat 3    # 모델은 같은 말에도 다르게 답합니다 — 여러 번 돌려 비율로 봅니다
```

과제 하나는 폴더 하나입니다.

| 자리 | 무엇 |
|---|---|
| `task.json` | `prompt`(시킬 말) · `check`(정답 검사 명령) · 고르면 `doneCheck`(위 완료 검사) · `timeout`(초) |
| `start/` | 시작 파일. 임시 폴더에 복사되고 deel 이 거기서 일합니다 |
| `golden/` | 정답 검사 파일. deel 이 **다 끝낸 뒤에** 들어갑니다 — 모델은 못 봅니다 |

채점은 정답 검사의 종료코드 하나로만 합니다. 결과는 `golden/.results/` 에 남고, 지난번과 견줘
**나빠진 과제**를 짚습니다. 모델을 바꾸거나 deel 을 올린 뒤 한 번 돌려 보세요. 바깥 게이트웨이면
`--online` 을 붙입니다. `check` 는 사람이 적은 명령이라 관문 없이 돕니다 — 남이 준 과제 모음은 먼저 읽어
보고 돌리세요.

## 막는 것과 못 막는 것

한 겹에 기대지 않습니다. 겹마다 못 막는 것이 있어서 겹쳐 씁니다.

| 겹 | 하는 일 | 못 하는 것 |
|---|---|---|
| **위험 명령 차단** | 디스크 포맷 · 재귀 삭제 · 강제 푸시처럼 되돌릴 수 없는 명령을 막습니다 | **금지 목록 방식**입니다. 목록이 모르는 꼴은 샐 수 있고, 찾을 때마다 막아 온 기록이 [릴리스 노트](releases.md)에 있습니다 |
| **정책 금지 규칙** | 관리자가 적은 도구·명령을 막습니다 | 적은 무늬만 막습니다 |
| **승인 (`strict`)** | 바꾸기 전에 사람이 diff 를 보고 정합니다 | 사람이 읽고 누르는 만큼만 지킵니다 |
| **되돌리기** | 고치기 전 스냅샷 → `/undo` | 파일만 돌아옵니다. 명령이 바깥에 낸 것(푸시 · DB · 메일)은 못 되돌립니다 |
| **감사 로그** | 한 일을 전부 적습니다 | 막지는 않습니다 — 나중에 봅니다 |

더 자세한 것은 [안전망과 사내 반입](safety.md).
