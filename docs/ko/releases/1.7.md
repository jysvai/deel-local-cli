## 1.7.0

**로컬은 그대로 두고, 말했을 때만 바깥으로 나갑니다**

1.6 까지 이 도구는 「완전 로컬」 이라고 말해 왔습니다. 그런데 코드가 지키던
것은 그 절반이었습니다.

```
.deel/config.json 의 baseUrl 한 줄
  http://127.0.0.1:1234/v1  →  https://api.어딘가.com/v1
```

이 한 줄이면 그대로 바깥으로 나갔습니다. 화면에 `↗` 가 뜨긴 했지만 그건
**알리는 것**이지 막는 것이 아닙니다.

| | 1.6.3 | 1.7.0 |
|---|---|---|
| 주소만 바깥으로 바꾸면 | 그대로 나감 | 안 나감 — 허가가 따로 필요 |
| 켤 때 무슨 판·무슨 모드인지 | 안 보임 | 첫 줄에 `deel 1.7.0  ⌂ 이 안` |
| 바깥에 붙었을 때 파일에서 읽은 열쇠 | 그대로 실려 나감 | 가려서 나감 |
| 모델이 가림표를 파일에 되쓰면 | 진짜 열쇠가 지워짐 | 막고 왜인지 말함 |
| 처음 설정 | 주소를 직접 침 | 골라서 붙음 (GPT · Claude · Gemini · Bedrock · 직접) |
| 열쇠를 붙여넣으면 | 어디 것인지 모름 | 앞머리로 알아채고 그 회사로만 감 |
| 안 붙을 때 | `HTTP 401` | 왜 막혔는지 + 열쇠 받는 곳 |
| Claude 를 직접 | 못 붙음 | 붙음 (규격이 다른 자리를 다 흡수) |
| 돈 | 안 보임 | 상태줄 누적 · 턴마다 (요금을 알 때만) |
| 채팅 치다 ↑ 를 누르면 | 치던 글이 사라짐 | ↓ 로 돌아옴 |
| 「1.6.3 이 뭐였지」 를 읽으면 | 111KB · 2,090줄 | 32KB |

### 모드가 셋입니다

```
deel            ⌂ 이 안    바깥 주소면 물어봅니다 (기본)
deel online     ↗ 바깥     물어보지 않습니다
deel offline    ⛊ 봉인     기억해 둔 허가까지 무시합니다
```

**주소와 허가가 둘 다 있어야 나갑니다.** 주소만 바꿔서는 못 나갑니다.

한 번 허락하면 그 연결은 다음부터 안 물어봅니다 — 설정에 `online: true` 로
남습니다. 그 칸이 있다는 것만으로도 「이 연결은 바깥이다」 라는 뜻이라,
설정 파일을 열어 본 사람이 그것만 보고도 압니다.

로컬·사내망(127.x · 10.x · 192.168.x · 172.16~31.x)은 셋 중 어느 모드에서도
그냥 갑니다. `offline` 은 「인터넷 없음」 이 아니라 「회사 밖으로 안 나감」
입니다.

### 붙일 곳을 골라서 붙입니다

`deel setup` 이 주소를 묻는 대신 물어봅니다.

```
1. 열쇠만 있습니다 — 어디 것인지 찾아 드립니다   빈칸 1개
2. 주소를 직접 넣기 (사내 게이트웨이 · 로컬)      빈칸 2개
3. OpenAI (GPT)                                  빈칸 1개
4. Anthropic (Claude)                            빈칸 1개
5. Google (Gemini)                               빈칸 1개
6. AWS Bedrock                                   빈칸 2개
```

1번이 핵심입니다. 열쇠 앞머리로 어디 것인지 짚어서 **한 곳만** 묻습니다.

```
❯ sk-ant-api03-••••
  ✓ Anthropic (Claude) 열쇠로 보입니다. (열쇠가 sk-ant- 로 시작합니다)
    여기저기 던지지 않습니다.
```

벤더마다 찔러 보는 식으로 만들면 Anthropic 열쇠가 OpenAI 서버로, 다시
Google 서버로 갑니다. 401 이 오고 끝이지만 **열쇠는 이미 갔습니다.**
그래서 모르는 열쇠는 짐작하지 않고 사람에게 묻습니다.

Bedrock 은 리전을 고릅니다 — 서울(ap-northeast-2) 을 포함해 다섯 곳과
「직접 입력」 이 있습니다.

### 안 붙을 때 무엇이 막았는지 말합니다

여태는 401 도 404 도 403 도 전부 「연결 실패」 한 마디였습니다. 이 셋은
고칠 자리가 완전히 다릅니다.

```
  ✗ 연결 실패
    ⚠ 열쇠는 닿았는데 이 모델을 못 씁니다 — 콘솔에서 모델 사용 신청을
      먼저 하세요 (Bedrock 은 모델마다 따로 신청합니다).
    열쇠 받는 곳  https://console.aws.amazon.com/bedrock/
```

### Claude 를 직접 붙일 수 있습니다

다섯 중 유일하게 **몸통 모양이 다릅니다.** 문 이름 · 몸통 · 답 읽기 ·
이력 되돌리기 · 도구 결과 · 흘려받기 여섯 자리를 따로 흡수했고, 그림과
창 크기까지 붙였습니다.

틀리면 전부 `400` 한 줄로 보이는 자리들입니다.

- 판 머리(`anthropic-version`) 하나가 없으면 열쇠가 멀쩡해도 400
- 시킴말은 `messages` 밖으로 나가야 함
- 차례가 사람·모델로 번갈아 와야 함 — 도구를 한 턴에 둘 부르면 결과가
  둘인데, 그대로 보내면 거절당함 (**하나 부를 때만 되는 고장**)
- 답이 글 한 덩어리가 아니라 블록 배열
- 토큰 이름이 다름 (`input_tokens` — `prompt_tokens` 를 찾으면 늘 0)

확인 못 한 것은 안 보냅니다. 생각 칸의 값 모양과 답 모양 강제는 문서에서
확인하지 못해 아예 안 싣습니다 — 짐작으로 넣은 칸 하나가 400 을 만들면,
화면에서는 열쇠가 틀린 것과 구별이 안 됩니다.

### 바깥으로 나갈 때는 파일 내용의 비밀도 가립니다

여태 비밀 가리기는 명령 출력만 가렸습니다. 파일에서 읽어 온 글은 일부러
안 가렸습니다 — 가리면 모델이 그 가림표를 다시 파일에 써서 사람의 진짜
열쇠를 지워 버리기 때문입니다.

그 저울은 로컬만 쓰던 때의 것입니다. `Read` 한 번이면 `.env` 가 통째로
남의 서버 로그에 남고, 그건 되돌릴 수가 없습니다.

잃는 쪽은 다른 자리에서 막았습니다. `Write`·`Append`·`Edit` 이 가린 표를
파일에 못 쓰게 막는 자물쇠를 **먼저** 넣었습니다.

```
✗ 쓰려는 내용에 가려진 표(«가림»)가 2군데 있습니다.
  그대로 쓰면 파일의 진짜 값이 그 표로 덮입니다.
  원래 값을 그대로 두려면 그 줄은 건드리지 마세요.
```

### 돈이 보입니다 — 다만 지어낸 요금은 안 찍습니다

```
❯ ─ 12.4초 · 도구 3회 · ↑8.2k ↓1.1k · $0.0271
```

**값이 박힌 요금표가 없습니다.** 요금은 회사가 아무 때나 바꾸는 값이고,
소스에 박아 두면 고칠 사람이 없습니다. 반년 뒤면 이 도구는 틀린 금액을
자신 있게 찍는 도구가 됩니다.

그래서 `.deel/config.json` 에 적으면 셈합니다.

```json
"요금": { "claude-opus-4-6": { "입력": 0, "출력": 0, "기준": "2026-09-01" } }
```

100만 토큰당 달러입니다 — 요금표에 적힌 숫자를 그대로 옮겨 적으면 됩니다.
금액 옆에 **어디서 온 값인지·언제 기준인지**가 같이 뜨고, 반년이 지나면
`· 오래됨` 이 붙습니다.

모르면 안 찍습니다. 로컬로만 쓰는 화면에는 돈 이야기가 아예 안 뜹니다.

### ↑ 를 눌러도 치던 글이 안 사라집니다

```
❯ 이 함수 좀 고쳐줘   ← 치던 중
↑                     이전 명령으로 바뀜
↓                     1.6.3: 빈 줄  ·  1.7.0: 「이 함수 좀 고쳐줘」
```

Node 판마다 동작이 달라서 나던 문제입니다. 새 Node 는 되돌려 주고 옛
Node 는 빈 줄을 줬습니다. 판에 기대지 않고 deel 이 직접 들고 있습니다.

`릴리스 노트에서 1.6.3 이 뭐였는지 봐줘` 한 마디에 2,090줄이 통째로 읽혔습니다.
이제 1.2 ~ 1.7 이 파일로 나뉘고, 차례는 20줄짜리 표입니다.
