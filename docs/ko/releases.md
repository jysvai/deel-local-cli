# 릴리스 노트

판마다 무엇이 어떻게 바뀌었나

2.0.0 은 이름이 바뀐 큰 판입니다. 그래서 **2.0 부터는 줄기마다 한 파일**로 두고,
그 앞의 1.x 는 **한 파일에 모았습니다.**

| | 어디 | 무엇 |
|---|---|---|
| **지금 판** | **[2.1.x](releases/2.1.md)** | [2.1.0](releases/2.1.md#210) — 맡기면 멈추지 않고, 묻게 하면 diff 를 보여 줍니다 — 「다 됐다」 는 검사가 정합니다 |
| 지난 판 | [2.0.x](releases/2.0.md) | [2.0.3](releases/2.0.md#203) — 2.0.2 는 npm 에 못 나갔습니다 — 이제 GitHub 릴리스는 npm 에 올라간 뒤에만 생깁니다 |
| | | [2.0.2](releases/2.0.md#202) — 2.0.1 까지 「낮음 · 미룸 · 못 잼」 으로 넘겨 둔 것을 다 잡았습니다 |
| | | [2.0.1](releases/2.0.md#201) — 2.0.0 에 있던 울타리 하나가 안 걸렸고, 관문 넷이 아무것도 안 막고 있었습니다 |
| | | [2.0.0](releases/2.0.md#200) — 있다고 적힌 울타리마다 실제로 걸리는지 다시 봤습니다 |
| 구버전 | [1.x 모음](releases/1.x.md) | 1.2.0 ~ 1.20.13 을 판마다 한 줄씩 |
